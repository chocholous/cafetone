# Apple Wallet pass assets

Drop PNGs here. Apple's requirements:

| File               | Size    | Purpose                        |
|--------------------|---------|--------------------------------|
| `icon.png`         | 29×29   | Lock-screen / notifications    |
| `icon@2x.png`      | 58×58   | Retina                         |
| `icon@3x.png`      | 87×87   | Retina+                        |
| `logo.png`         | ≤160×50 | Shown on pass front            |
| `logo@2x.png`      | retina  |                                |
| `strip.png`        | 375×123 | Optional banner (storeCard)    |
| `strip@2x.png`     | 750×246 |                                |

Only `icon.png` and `icon@2x.png` are mandatory. Everything else is polish.

Use transparent PNGs for crisper rendering on dark backgrounds.
